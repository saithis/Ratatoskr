Demo scenarios

  1. Inventory inbox poison (Throw mode): Cycle Inventory to throw, place an order (outbox). The command handler fails; the inbox processor retries with backoff until poisoned. Turn mode to off, then Requeue on the poisoned row.
  2. Business rejection (Reject mode): Cycle Inventory to reject, place an order. Inventory publishes OrderFailed; OrderService inbox marks the order Failed.
  3. Rabbit retry + DLQ (notifications): Toggle Notification failure, place an order. The notification handler throws on the consumer thread (no inbox), so Rabbit retry (3 × 5 s) then DLQ ecommerce.events.notifications.dlq — inspect in RabbitMQ Management.
